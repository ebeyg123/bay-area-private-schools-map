# Bay Area Private / Non-Public Schools Map

Interactive map of 72 private and non-public schools across the Bay Area (Alameda, Contra Costa, Marin, San Francisco, San Mateo, Santa Clara, Santa Cruz, Solano, Sonoma).

## Color coding
- **Green** – Elementary (high grade ≤ 8)
- **Red** – High School (primarily grades 7–12 or 9–12)
- **Blue** – K-12 / Mixed (spans elementary through high school)

## Features
- Click markers for school name, grades, address, and website
- Layer control (top-right) to filter by level or switch base map
- Cluster view + individual colored markers

Data compiled from California private school listings.
